## 正文

你有没有遇到过这种情况——

花了好几天时间，用 LabelMe 或者 LabelImg 把几千张图片标注完了。  
结果对方说：「我们训练用的是 YOLO 格式，你这个 JSON 文件没法直接用。」

或者：

标注完了，图片和标签放在一起，但不知道有没有漏标，有没有空文件，有没有哪张图片根本没有对应的标签……  
只能一个个翻文件夹，眼睛看花了也不一定找得全。

又或者：

老师/领导让你把数据集按 8:1:1 划分成训练集、验证集和测试集，还要生成一个 `data.yaml`……  
你打开搜索框，搜「YOLO 数据集划分 python 脚本」，然后复制了一段代码，改了半个小时还是跑不起来。

---

**这些事情，其实本来不需要写代码。**

---

### 做 AI，不是只有程序员才有资格

在很多人的印象里，AI 开发是程序员的专属领域。  
标注工具嘛，LabelMe、LabelImg、CVAT——这些大家都知道，打开就能画框。

但标注完之后呢？

格式转换、质量检查、文件整理、数据集划分、增强……  
这些活儿，似乎只能靠"懂代码的人"来收尾。

一个做图像采集的人、一个负责标注质量管理的人、一个学计算机视觉的大学生——  
他们花了大量时间做标注，却在最后的数据处理环节被卡住了，只能去求会写 Python 的同事帮忙。

这不合理。

---

### 它和 LabelMe、CVAT 不一样

先说清楚一件事：

**Easy Dataset Station 不是标注工具。**

LabelMe、LabelImg、CVAT 做的是「画框」这件事——在图片上标出目标的位置和类别。这是数据集制作的核心环节，它们做得很好。

Easy Dataset Station 做的是**标注之后**的那些事：

> 标注好了，然后呢？

| 你遇到的问题 | Easy Dataset Station 怎么解决 |
|---|---|
| 标注完不知道有没有漏标 | 一键质量检测，孤立图片、空标签全部列出来 |
| 格式不对，训练框架不认 | LabelMe JSON / VOC XML → YOLO TXT，图形界面操作，30 秒转完 |
| 不知道各类别标注数量是否均衡 | 类别分布图，哪个类别样本太少一眼看出 |
| 要按比例划分训练集和验证集 | 填入比例，自动划分，自动生成 data.yaml |
| 文件命名乱七八糟 | 批量重命名，规范化文件名 |
| 要把几个数据集合并 | 多路径合并，类别 ID 自动重映射，不冲突 |
| 只有视频，没有图片 | 视频帧提取，均匀采样，直接输出图片 |
| 样本太少，想做数据增强 | 翻转、旋转、亮度调整……实时预览效果 |
| 要把数据集打包发给别人 | 一键 ZIP 导出，可选子集 |

这些功能，在 LabelMe 里找不到。  
它们通常只存在于某个不知道从哪里找来的 Python 脚本里。

### 打开就用，不需要装 Python 环境（或者只需要装一次）

Easy Dataset Station 是一个桌面应用，下载安装包，双击安装，就能打开。

第一次使用会引导你配置一下 Python 环境（如果你的电脑上已经有 Anaconda，选一下就行）。  
之后每次打开，直接用，不需要打开命令行，不需要记任何命令。

它能运行在 Windows 上（macOS 和 Linux 也在支持中）。

---

### 普通人也能做的事：一个真实的使用流程

假设你是一个不会写代码的人，手上有一批用 LabelMe 标注好的图片。

**第一步**：打开 Easy Dataset Station，选择「格式转换」，把 LabelMe 的 JSON 文件批量转成 YOLO 格式的 TXT 文件。操作：选择源目录 → 选目标目录 → 点击转换。完成。

**第二步**：打开「数据集质量检测」，选择图片目录和标签目录，点击「开始检测」。十几秒后，报告出来了：
- 图片 3,842 张，标签 3,839 张
- 孤立图片（无对应标签）3 张
- 空标签文件 12 个
- 类别分布：class_0 有 8,231 个框，class_1 只有 203 个框（严重不均衡）

你不需要懂代码，就能发现数据集的问题所在。

**第三步**：打开「数据集划分」，填入 0.8 / 0.1 / 0.1，点击划分。自动生成 train / val / test 三个文件夹和 data.yaml。

三个步骤，全程不需要打开终端，不需要写一行代码。

### 轻量，是它的设计哲学

现在也有一些在线数据集平台，功能很强大，但需要把数据上传到云端。

对于涉及隐私的工业数据、医疗影像、安防视频——上传云端是不现实的。

Easy Dataset Station 的所有计算都在本地完成。  
数据不离开你的电脑。

它不试图成为一个「大而全」的平台，  
它只做标注之外那些**最常用但最难找到趁手工具**的功能。
