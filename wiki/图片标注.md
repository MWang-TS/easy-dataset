# 图片标注

左侧导航 **图片标注**。用于手工绘制标注、修正已有标注，以及用模型做 AI 自动预标注。

> 与其它页面一样，所有操作都在本机完成；标注文件按 YOLO TXT 写入磁盘。

---

## 1. 两种工作模式

| 模式 | 适用场景 | 需要填写 |
|---|---|---|
| **已有数据集修改** | 图片与 `.txt` 已配对（`images/` + `labels/`，或同目录同名） | 数据集路径；需要另存时再填「标注输出路径」 |
| **全新标注** | 只有一个图片文件夹，还没有标签 | 原始图片路径 + **标注输出路径（必填）** |

要点：

- 「标注输出路径」留空 = **原地修改**已有标签；填了就写到新目录，原文件不动。
- 全新标注会先在「标注类型」里选定类型（见下节），**同一工作内类型锁定**，要换类型请关闭当前工作再新建。
- 打开过的路径会记入 **最近工作（最多 30 条）**，点击即可回到上次的文件夹。
- 图像/标签子目录名不规整（如 `img/`、`txt/`）时，在「图像文件夹」「标注文件夹」里手动指定。

---

## 2. 三种标注类型

| 类型 | 绘制方式 | 存储格式（归一化 0–1） |
|---|---|---|
| **目标检测** | 矩形，拖拽两个角 | `class cx cy w h` |
| **旋转框（OBB）** | 拖出矩形 → 拖框顶圆形手柄旋转 → 拖角点改尺寸 | `class x1 y1 x2 y2 x3 y3 x4 y4` |
| **分割** | 多边形，逐点单击，闭合结束 | `class x1 y1 … xn yn`（≥3 点） |

- 打开已有数据集时，页面按标签内容自动判断类型（检测 / 旋转框 / 分割 / 检测+分割 / 无标注），不匹配的绘制模式会被禁用并提示原因。
- 旋转框是"矩形旋转一定角度"，不是任意四边形；判定的几何条件是**对边等长 + 邻边垂直**，所以 4 点的分割多边形不会被误判成 OBB。
- 旋转框只能导出为 OBB（8 坐标），**不能降级成矩形**；导出面板里 OBB 数据集会禁用「检测」模式。

---

## 3. 画布工具与操作

| 工具 / 快捷键 | 说明 |
|---|---|
| `H` | 矩形（目标检测） |
| `R` | 旋转框 |
| `P` | 多边形（分割） |
| `Z` | 平移 / 预览（只读，右侧面板不可编辑） |
| `A` / `D` | 上一张 / 下一张 |
| 滚轮 | 缩放画布（以指针为中心） |
| 中键拖动 | 任意模式下平移视图 |
| `Ctrl+C` / `Ctrl+V` | 复制选中标注框 / 粘贴（可跨图片） |
| `Delete` | 删除选中标注框 |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 撤销 / 重做 |

补充操作：

- **右键菜单**：复制、粘贴、删除当前框。
- **复制选中并粘贴**（右侧面板按钮）：在原地偏移一点生成副本，适合密集同类目标。
- **角度输入**：选中旋转框后，右侧面板可精确填写角度（度）。
- **跳转**：点击画布右下角序号，输入数字回车直达指定图片。
- **标签半透明**：勾选后类别文字 90% 透明，避免遮挡小目标。
- **自动沿用上一张**：切到下一张时若该图还没有标签文件，自动绘制与上一张相同的标注（视频连续帧很省事）。

---

## 4. 类别管理

- 「全局类别」对所有图片生效；修改名称立即反映到所有标注框。
- 「新框类别」决定新画的框默认用哪个类别，默认沿用上一个框的类别。
- 类别来源优先级：显式指定的类别文件 → 自动探测 `classes.txt / class.txt / obj.names / classes.names` → `data.yaml / dataset.yaml` → 从现有标签的 `class_id` 推断（显示为 `class 0`、`class 1`…）。
- 类别名会自动写回同目录的 `classes.txt`（有则覆盖），下次打开自动恢复。

---

## 5. 保存

- 默认**自动保存**：编辑后延迟写入，标题栏显示「已保存 / 保存中…」。
- 「立即保存」按钮可强制马上落盘。
- AI 预标注与自动沿用都会走同一套写入逻辑，无需额外保存。

---

## 6. AI 自动预标注

1. 标题栏右侧打开 **启用自动标注** 开关（关闭状态下不显示模型配置）。
2. 选择模型文件，留空则用内置 `models/yolov8m.pt`。
   - 支持 ultralytics 可加载的任意权重：YOLOv5～v12、RT-DETR；
   - 检测 / 分割 / 旋转框三种任务模型均可；
   - 导出格式：`.pt`、`.onnx`、`.engine`、`.torchscript`、`.tflite`、OpenVINO 目录。
3. 设置 **置信度阈值**，按需勾选 **覆盖已有标注**（不勾选只补空白图）。
4. 点 **开始自动标注**；进度实时刷新，可随时 **停止**。

注意事项：

- 需要后端 Python 环境安装 `ultralytics`，页面会先检测环境并给出提示。
- 分类模型（`classify`）不支持自动标注，会提示任务类型不受支持。
- 旋转框模型输出会写入 8 坐标行；分割模型输出优先写多边形，没有 mask 时退回外接矩形。
- 推理结果类别名以模型自带 `names` 为准；与数据集类别不一致时，请先统一类别再标注。

---

## 7. 导出数据集

| 导出模式 | 行为 |
|---|---|
| **原始** | 原样复制标签，不做坐标变换 |
| **检测** | 每个目标转成一个外接矩形；OBB 数据集禁用此模式 |
| **分割** | 保留多边形；矩形/旋转框会转成 4 点多边形 |

- 「训练集比例」用于按比例切分（其余进验证集），「同时复制图片」勾选后连图片一起拷到目标目录。
- 导出结果为标准 YOLO 结构：`images/` + `labels/`，可直接用于 ultralytics 训练。
- OBB 数据集训练时需在命令或 YAML 中指定 `task=obb`。

---

## 8. 建议工作流

1. 质量检测确认图片/标签配对与类别分布。
2. 图片标注里先修正 10～20 张难点样本。
3. 用训练好的模型做 AI 预标注，再人工过一遍低置信度区域。
4. 导出 → 在客户端「数据集划分」生成 `data.yaml` → 训练。
