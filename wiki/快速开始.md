# 快速开始

## 1. 安装客户端

从发布页下载对应平台安装包（Windows 推荐 `.exe`（NSIS））并安装。
安装完成后启动 **Easy Dataset**，首次运行会进入配置向导。

## 2. 首次配置

客户端本身不含 Python，需要指定一个可用的 Python 环境（该环境要装好 `requirements.txt` 里的依赖）。

### 方式 A：使用已有 Conda 环境（推荐）

1. 选择「使用 Conda 环境」，客户端会自动扫描本机所有 conda 环境；
2. 列表中每个环境会显示 Python 版本，并用颜色标注依赖是否齐全：
   - 绿色：`Flask / Flask-SocketIO / Flask-Cors / opencv-python / Pillow` 齐全；
   - 红色：缺少依赖，展开可看到缺失项，按提示安装即可。
3. 选择目标环境 → 确认 → 启动。

### 方式 B：手动指定 Python

直接填写（或浏览选择）`python.exe` / `python` 的绝对路径，确认后启动。

> 依赖不全时向导会阻止启动并给出 `pip install …` 命令。

### 安装后端依赖（如需要）

```bash
conda create -n easy-dataset python=3.10
conda activate easy-dataset
pip install -r requirements.txt
```

需要使用 AI 自动标注 / 智能抽帧时，再安装：

```bash
pip install ultralytics          # 会带上 CPU 版 torch
# GPU 加速请按 CUDA 版本单独安装 torch
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
```

`ffmpeg`（AI 抽帧快速分段用）可通过 conda 安装：`conda install -c conda-forge ffmpeg`。

## 3. 界面结构

```
┌ 标题栏：产品名 / 版本 / 后端状态 / 主题 / 语言
├ 左侧栏：功能导航（质量检测、可视化、标注、转换、标签、文件、划分、合并、视频）
│   └ 每个页面的参数面板（可折叠）
├ 主区域：当前页面的工作区
└ 状态栏：后端状态、滚动提示（快捷键与技巧，可关闭）、版本号
```

- 左侧栏可用 `Ctrl/Cmd + B` 收起 / 展开；宽度可拖拽。
- 主题（深色/亮色）与语言（简体中文 / English / 日本語）在标题栏切换，自动记忆。

## 4. 后端启动与停止

- 客户端启动时会自动拉起本地后端（默认端口 `18081`，仅监听 127.0.0.1）；
- 标题栏的后端状态点可查看状态、重启后端、查看日志；
- 关闭客户端会自动结束后端及其子进程（不会残留黑窗）。

若状态显示异常，进入 **系统管理 → 环境管理 → 重新配置** 重新选择 Python 环境。
