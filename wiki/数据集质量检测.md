# 数据集质量检测

用于快速判断一个数据集「能不能用、缺什么、偏不偏」。

## 1. 两种加载方式

| 方式 | 操作 | 适用 |
|---|---|---|
| YAML 加载 | 选择 `data.yaml` / `dataset.yaml` | 标准 YOLO 数据集（自动解析 `path` / `train` / `val` 与 `names`） |
| 手动加载 | 分别选择图片目录、标签目录 | 目录结构不标准，或只有图片/标签其中一侧 |

> YAML 里 `path` 建议写相对路径（如 `path: .`），否则换机器后解析不到图片目录。

## 2. 分析结果

### 2.1 概览

| 指标 | 含义 |
|---|---|
| 图片总数 / 标签总数 | 实际扫描到的文件数量 |
| 标注框 | 标签文件中的有效行数 |
| 类别数 | 出现过的类别 ID 数量 |
| 配对成功 | 同名图片与标签都存在 |
| 孤立图片 / 孤立标签 | 只有图片没有标签 / 只有标签没有图片 |
| 空标签 | 大小为 0 的标签文件 |

### 2.2 标注类型

新增卡片显示数据集实际使用的标注形式，便于确认数据是否混用：

| 字段 | 说明 |
|---|---|
| 标注类型 | 目标检测 / 旋转框 / 分割 / 混合 / 无标注 |
| 矩形框行数 | `class cx cy w h` 行数 |
| 多边形行数 | 多边形行数（分割 + 旋转框合计） |
| 旋转框行数 | 4 个点且**确实构成矩形**（对边等长 + 邻边垂直）的行数 |

> 4 个点的分割多边形不会被误判为旋转框。若「标注类型」显示「混合」，通常说明数据集里同时存在矩形与多边形，训练前需统一。

### 2.3 类别分布

按类别统计框数量与占比，用来发现长尾类别（过少）或某个类别压倒性多（模型会偏）。

### 2.4 框统计与分布

| 指标 | 说明 |
|---|---|
| 平均面积 / 平均宽高比 | 多边形按真实几何面积计算（不是外接矩形） |
| 小目标 / 大目标 | 面积 < 0.5% / > 10%（相对图片面积） |
| 面积直方图 | 7 个区间，判断是否全是小目标 |
| 宽高比直方图 | 判断目标形状是否极端（细长物体） |

### 2.5 问题文件

列出孤立图片、孤立标签、空标签的具体路径，可直接复制路径到「文件管理」或「图片标注」页修复。

## 3. 导出报告

点击「导出报告」生成文本报告（Markdown），可用于归档或团队评审。

## 4. 历史记录

每次分析会保留一条记录（数据集名、时间、图片数），点击可回看当时结果，支持删除。

## 5. 建议的检查顺序

1. 看「孤立标签 / 孤立图片」是否为 0；
2. 看「空标签」数量（负样本可以存在，但要确认是有意为之）；
3. 看「标注类型」是否与训练任务一致（检测 / OBB / 分割）；
4. 看类别分布与面积直方图是否严重失衡；
5. 到 [数据集可视化](数据集可视化.md) 抽样目测几张。
