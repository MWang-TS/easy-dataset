# Easy Dataset 使用说明书

> 适用版本：v1.0.0 及以后
> 产品形态：Windows / macOS / Linux 桌面客户端（Tauri 2 + React + 本地 Flask 后端）

Easy Dataset 是面向 YOLO 数据集的本地工具：不依赖云服务，所有读写都在本机完成。
覆盖「质量检测 → 可视化核对 → 标注/修正 → 划分/合并 → 导出」的完整流程。

---

## 1. 它能做什么

| 模块 | 说明 |
|---|---|
| 数据集质量检测 | 统计图片/标签/标注框数量，检查孤立文件、空标签、类别失衡，面积与宽高比分布 |
| 数据集可视化 | 带标注叠加预览，按「已标注 / 未标注 / 类别」过滤，一键跳转修复 |
| 图片标注 | 目标检测（矩形）、旋转框（OBB）、实例分割（多边形）三种类型；AI 自动预标注；导出 YOLO 标签 |
| 格式转换 | LabelMe ↔ YOLO、Pascal VOC → YOLO、YOLO → VOC、类别 ID 重映射、YOLO → COCO JSON |
| 标签编辑 | 批量替换 / 删除类别 ID、多 ID 重排序 |
| 文件管理 | 一致性检查、删除空标签、创建空标签、批量重命名、修复损坏图片 |
| 数据集划分 | 按比例随机划分 train / val / test，自动生成 `data.yaml` |
| 数据集合并 | 多来源合并，支持类别 ID 偏移与显式重映射，自动处理重名 |
| 视频抽帧 | 均匀抽帧；AI 智能抽帧只保留含目标类别的帧，输出图片与 YOLO 标签 |
| 系统管理 | 环境管理（Conda 环境扫描/切换）、环境依赖清单（导出 Easy Conda `environment.yml`）、关于与更新 |

## 3. 系统要求

| 项 | 要求 |
|---|---|
| 操作系统 | Windows 10/11 x64、macOS 12+（Apple Silicon）、Linux x64 |
| Python | 3.10+（推荐 3.10），需包含 `requirements.txt` 中的依赖 |
| 磁盘 | 建议预留数据集体积 2 倍以上空间（预览/导出会生成副本） |
| 可选 | `ultralytics` + `torch`（AI 自动标注 / 智能抽帧）、`ffmpeg`（AI 抽帧快速分段） |

依赖清单可在客户端 **系统管理 → 环境依赖** 中查看并导出，见 [系统管理与环境依赖](系统管理与环境依赖.md)。

## 4. 数据格式约定

- 标注文件为 YOLO TXT，一行一个目标，坐标均为 **归一化 0–1**：

| 类型 | 行格式 | 示例 |
|---|---|---|
| 目标检测 | `class cx cy w h` | `0 0.500000 0.500000 0.120000 0.240000` |
| 旋转框 OBB | `class x1 y1 x2 y2 x3 y3 x4 y4`（4 个角点，矩形旋转） | `0 0.100000 0.100000 0.400000 0.120000 0.380000 0.420000 0.080000 0.400000` |
| 实例分割 | `class x1 y1 x2 y2 … xn yn`（≥3 个点） | `0 0.10 0.10 0.40 0.10 0.40 0.30 0.25 0.45` |

- 目录推断规则：路径中最后一个 `images` 目录段替换为 `labels`，文件名后缀换成 `.txt`；
  也支持 `images/train`、`images/val` 等分目录结构；命名不规整时可在标注页手动指定图像/标签目录。
- 类别文件支持 `classes.txt`（每行一个类别名）或 `data.yaml`（`names` 为列表或字典）。
  自动探测优先级：`classes.txt / class.txt / obj.names / classes.names` → `data.yaml / dataset.yaml` → 其它 `*.yaml`。

## 5. 隐私

- 后端仅监听 `127.0.0.1`，不对外暴露；可选 `API_TOKEN` 鉴权（放在运行目录的 `.env`）。
- 不收集、不上传任何数据；更新检查只读取公开发布清单。
