# 格式转换与数据处理

本章覆盖 6 个页面：格式转换、标签编辑、文件管理、数据集划分、数据集合并、视频抽帧。

---

## 1. 格式转换

左侧导航 **格式转换**，先选「转换模式」，填写目录后点「开始转换」。

| 模式 | 输入 | 输出 | 说明 |
|---|---|---|---|
| **LabelMe → YOLO** | LabelMe JSON 目录（+ 图片目录） | YOLO TXT | 多边形保留为分割行（`class x1 y1 …`），矩形转 `cx cy w h` |
| **VOC → YOLO** | Pascal VOC XML 目录（+ 图片目录） | YOLO TXT | 类别名自动排序生成 ID，可编辑「类别名称」 |
| **YOLO → VOC** | YOLO 数据集根目录 / 标签目录 | VOC XML | 多边形与旋转框都取**外接框**，丢失角度与轮廓 |
| **类别重映射** | YOLO 标签目录 | 原地或新目录 | 每行 `旧ID=新ID`，用于合并前统一类别空间 |
| **YOLO → COCO JSON** | YOLO 数据集 | 单个 `.json` | 分割数据写真实 `segmentation` 多边形与 `area`（鞋带公式），检测写 bbox |

小贴士：

- 转换前建议先备份，尤其「原地修改」类操作。
- VOC 转换需要图片目录来读取宽高，否则坐标无法归一化。
- COCO 导出时「类别名称」留空会自动命名 `class_0`、`class_1`…。

## 2. 标签编辑

左侧导航 **标签编辑**，用于批量修复 `class_id`，不用写脚本。

| 操作 | 用途 |
|---|---|
| 替换类别 ID | 把某个 ID 全量替换成另一个 ID |
| 删除类别 | 删除指定类别 ID 的所有标注行 |
| 重排类别 | 批量 `原ID → 新ID` 映射，一次整理整套类别顺序 |
| 重命名 | 修改类别名称（写回 `classes.txt`） |

- 勾选 **原地修改** 时直接覆盖原文件（**会先备份提示，请自行留副本**）；不勾选则输出到新目录。
- 执行后会显示受影响的文件数。

## 3. 文件管理

左侧导航 **文件管理**，处理结构层面的问题。

| 功能 | 说明 |
|---|---|
| 图片-标签一致性检查 | 统计配对数、孤立图片（无标签）、孤立标签（无图片），列出具体路径 |
| 删除空标签文件 | 清理 0 字节 TXT |
| 为未标注图片创建空标签 | 背景图/负样本的常规做法 |
| 批量重命名 | 按前缀 + 序号重命名图片和标签，保证同名配对 |
| 修复损坏图片 | 重新保存截断/损坏的 JPEG，可调质量 |

- 「预览模式」只显示结果不落盘，建议先预览再执行。
- 删除操作不可撤销，执行前请确认路径正确。

## 4. 数据集划分

左侧导航 **数据集划分**：按比例拆 `train / val / test`，并生成 `data.yaml`。

1. 填写图片目录、标签目录、输出目录。
2. 设置三个比例，**总和必须等于 1.00**（如 0.8 / 0.2 / 0.0）。
3. 可选：修改随机种子（同种子结果可复现）、填写类别名称列表。
4. 勾选 **自动生成 data.yaml** 后点「开始划分」。

产出为标准结构：

```
输出目录/
├── data.yaml
├── images/{train,val,test}/
└── labels/{train,val,test}/
```

## 5. 数据集合并

左侧导航 **数据集合并**：把多个来源合成一个，并统一类别空间。

1. 「添加数据源」，每个来源填图片目录 + 标签目录。
2. 需要时设置 **类别偏移**（所有 `class_id` 加固定值），或使用「类别映射」显式映射。
3. 设置「输出图片目录」「输出标签目录」。
4. 可选 **文件名添加来源编号前缀**，避免不同来源的同名图片互相覆盖。
5. 点「开始合并」，结束后会报告图片/标签数、冲突重命名数与警告。

注意：

- 合并只做文件复制与 ID 变换，不修改源数据。
- 若两个来源里同一 `class_id` 语义不同，**务必**用类别映射或偏移，否则训练时类别会混淆。

## 6. 视频抽帧

左侧导航 **视频抽帧**，两种模式。

### 6.1 普通抽帧

| 参数 | 说明 |
|---|---|
| 抽帧间隔（帧） | 每 N 帧取一张 |
| 输出格式 | JPG / PNG |
| JPEG 质量 | 1–100 |
| 文件名前缀 | 如 `frame` → `frame_000001.jpg` |

先「加载视频信息」可看到 FPS、总帧数、分辨率、时长与预计抽取数量。

### 6.2 AI 智能抽帧

只保留画面中含目标类别的帧，适合从长视频里挖有效样本。

1. 切到 **AI智能抽帧**，页面会自动检测 `ultralytics` 是否可用。
2. 选择模型（`.pt/.onnx/.engine/.torchscript/.tflite`，支持检测/分割/旋转框模型）。
3. 填 **目标类别**（逗号分隔，类名与模型 `names` 一致）与 **置信度阈值**。
4. 采样间隔 = 每隔 N 帧送检一次。
5. 可选 **分段并行模式**：先按「每段时长」切段再并行推理，解决超长视频 seek 竞争问题；
   24 小时视频建议 60 min/段、并行 4～8 段。

输出目录里同时写入抽出的图片与对应的 YOLO 标签，可直接进入标注页修正。

---

## 7. 推荐处理顺序

```
原始素材 → 视频抽帧 → 质量检测 → 删除空标签/建空标签 → 标注/修正
        → 格式转换（外部队列）→ 标签编辑（统一 ID）→ 划分 → 训练
多来源时：各自清洗 → 标签编辑统一 ID → 数据集合并 → 质量检测复核 → 划分
```
