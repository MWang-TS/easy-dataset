# 数据集可视化

按「标注状态 / 类别」浏览图片，快速目测标注质量。

## 1. 加载

- 选择图片目录 + 标签目录（或从 YAML 加载）；
- 选择后自动列出图片并生成缩略图。

## 2. 过滤与浏览

| 控件 | 作用 |
|---|---|
| 全部 / 已标注 / 未标注 | 按是否存在标签文件过滤 |
| 类别过滤 | 只看包含指定类别的图片 |
| 分页 | 大目录按页加载，避免一次性拉太多缩略图 |

缩略图卡片显示文件名与框数量（`box_count > 0` 才显示），点击进入大图预览。

## 3. 预览中的标注画法

预览图由后端合成，三种标注类型的呈现方式不同：

| 类型 | 画法 |
|---|---|
| 目标检测 | 矩形边框 + 类别标签 |
| 实例分割 | 多边形半透明填充 + 轮廓 + 类别标签 |
| 旋转框 OBB | 4 点轮廓 + 顶点圆点（不填充），与分割在视觉上区分 |

坐标按图片真实尺寸换算，类别名来自 `classes.txt` / `data.yaml`；没有类别名时显示类别 ID。

## 4. 常见用途

- 核对「空标签」是否真为负样本；
- 检查小目标是否标全、框是否贴边；
- 确认旋转框角度是否符合预期；
- 发现标签错位（图片与标签不同源）时，回到 [图片标注](图片标注.md) 修正。
