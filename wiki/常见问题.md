# 常见问题

---

## 1. 后端起不来 / 一直转圈

**现象**：界面顶部提示服务异常，或页面一直是加载状态。

排查顺序：

1. 打开 **系统管理 → 环境管理**，确认当前环境的依赖是否齐全（标记 `✓`）。
2. 缺依赖就安装：

   ```bash
   pip install -r requirements.txt
   ```

3. 确认所选 Python 确实可执行：在命令行跑 `<python 路径> -c "import flask, PIL; print('ok')"`。
4. 端口被占用时，换端口或结束占用进程：

   ```powershell
   netstat -ano | findstr :18081
   ```

5. 仍不行则 **系统管理 → 重新配置**，重新走一遍首启向导。

## 2. 接口 404 / `Failed to fetch` / `Unexpected token '<'`

**含义**：前端请求打到了"不认识这个接口"的后端，或者后端没起来（返回 HTML 而不是 JSON）。

已修复的历史问题（v1.0.0 起）：升级后客户端仍跑旧后端代码，原因是资源同步只在首次配置时执行。
现在改为**每次启动都按版本号同步到独立运行目录**（`%LOCALAPPDATA%\com.easyolo.easy-dataset\backend_runtime\<版本>`），
旧版本的目录会在退出时清理。

若仍出现：

1. 完全退出客户端（含托盘）后重新打开；
2. 到 `%LOCALAPPDATA%\com.easyolo.easy-dataset\backend_runtime\` 确认存在当前版本号目录，且文件时间戳是本次安装时间；
3. 查看后端日志 `%TEMP%\easy_dataset_backend.log`，确认是否有 import 报错（通常是缺依赖）；
4. 系统管理里重新配置一次环境。

## 3. AI 自动标注不可用

| 提示 | 原因与处理 |
|---|---|
| 当前 Python 环境不支持自动标注 | 该环境没装 `ultralytics`，`pip install ultralytics` 后重开页面 |
| 模型文件不存在 / 格式不支持 | 只接受 `.pt/.onnx/.engine/.torchscript/.tflite/.mlpackage` 或 OpenVINO 目录 |
| 分类模型不支持 | `classify` 任务模型不能做框标注，换检测/分割/OBB 模型 |
| 置信度太低导致框太杂 | 提高阈值；或先不勾「覆盖已有标注」 |

AI 智能抽帧同理，需要 `ultralytics`；分段并行还需要 `ffmpeg` 在 PATH 中。

## 4. 旋转框相关

- **旋转框是什么形状？** 矩形整体旋转一个角度，不是任意四边形。判定条件：对边等长 + 邻边垂直。
- **为什么我的 4 点多边形被识别成"分割"？** 因为它不满足矩形条件；这是正确的判定，避免把分割数据当 OBB 导出。
- **OBB 数据集为什么不能导出成"检测"？** 旋转框降级成矩形会丢角度信息，工具直接禁止该组合，请选「原始」或「分割」。
- **训练 OBB 数据集**：ultralytics 需要 `task=obb`（例如 `yolo obb train data=xxx.yaml model=yolov8n-obb.pt`）。

## 5. 类别问题

| 现象 | 处理 |
|---|---|
| 打开数据集后类别名变成 `class 0/1/2` | 没有 `classes.txt`/`data.yaml`，可在右侧面板重命名，会自动写回 `classes.txt` |
| 重开客户端类别丢了 | 确认标注目录可写；类别会写入同目录 `classes.txt` 作为兜底 |
| 合并后类别错乱 | 合并前用「标签编辑」统一 ID，或在合并页设置类别偏移/映射 |

## 6. 标签/图片对不上

- 命名必须**同名不同后缀**：`abc.jpg` ↔ `abc.txt`。
- 支持 `images/` + `labels/` 平行结构；也支持图片和 txt 同目录。
- 子目录名不规整（`img/`、`ann/`）时，在标注/质量检测页**手动指定**图像与标签目录。
- 用 **文件管理 → 一致性检查** 找出孤立图片/孤立标签，再用「批量重命名」对齐。

---

## 7. 安装包相关

| 现象 | 说明 |
|---|---|
| 首次启动比平时慢 | 会把内置后端资源同步到运行目录，仅首次或升级后发生 |
| 升级后功能还是老的 | 退出后重开，确认运行目录版本号已变；必要时系统管理 → 重新配置 |
| 杀毒软件拦截 | 客户端会调用本地 Python 与 ffmpeg 子进程，需允许 |
| 更新提示但装不上 | 手动到发布页下载安装包覆盖安装 |

---

## 8. 日志与数据位置

| 内容 | 位置 |
|---|---|
| 后端运行目录 | `%LOCALAPPDATA%\com.easyolo.easy-dataset\backend_runtime\<版本>\` |
| 后端日志 | `%TEMP%\easy_dataset_backend.log` |
| 界面配置（路径、主题、语言） | 应用本地存储（localStorage），退出不清除 |
| 你的数据集 | 始终在你选择的目录，工具不复制到别处 |
